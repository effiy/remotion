# @remotion/preload

Preloads assets for use in Remotion

[![NPM Downloads](https://img.shields.io/npm/dm/@remotion/preload.svg?style=flat&color=black&label=Downloads)](https://npmcharts.com/compare/@remotion/preload?minimal=true)

---

## 💡 概述

Preloads assets for use in Remotion videos, helping ensure smooth playback and rendering by fetching resources ahead of time.

---

## ⚡ 功能

- Preload media assets before rendering
- Reduce first-frame latency
- Works with Remotion's asset resolution system
