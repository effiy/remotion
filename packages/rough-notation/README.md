# @remotion/rough-notation

Rough annotation primitives for Remotion

[![NPM Downloads](https://img.shields.io/npm/dm/@remotion/rough-notation.svg?style=flat&color=black&label=Downloads)](https://npmcharts.com/compare/@remotion/rough-notation?minimal=true)

---

## 💡 概述

Rough annotation primitives for Remotion, providing hand-drawn style annotation effects such as underlines, boxes, circles, and highlights for use in video compositions.

---

## ⚡ 功能

- Hand-drawn style annotation effects
- Underline, box, circle, and highlight primitives
- Animated annotation reveal within the Remotion timeline
- Rough.js-based rendering for sketch-like aesthetics
