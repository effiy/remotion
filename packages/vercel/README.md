# @remotion/vercel

Render Remotion videos on Vercel Sandbox

[![NPM Downloads](https://img.shields.io/npm/dm/@remotion/vercel.svg?style=flat&color=black&label=Downloads)](https://npmcharts.com/compare/@remotion/vercel?minimal=true)

---

## 💡 概述

A Remotion package for rendering videos on the Vercel Sandbox infrastructure, enabling serverless video generation directly within the Vercel platform.

---

## ⚡ 功能

- Serverless video rendering on Vercel Sandbox
- Vercel Blob storage integration
- Compatible with Next.js deployments on Vercel

## 🚀 快速开始

### Installation

```bash
npm install @remotion/vercel --save-exact
```

When installing a Remotion package, make sure to align the version of all `remotion` and `@remotion/*` packages to the same version.
Remove the `^` character from the version number to use the exact version.
