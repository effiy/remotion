# @remotion/whisper-webgpu

Transcribe audio in the browser using Whisper and WebGPU

[![NPM Downloads](https://img.shields.io/npm/dm/@remotion/whisper-webgpu.svg?style=flat&color=black&label=Downloads)](https://npmcharts.com/compare/@remotion/whisper-webgpu?minimal=true)

---

## 💡 概述

A Remotion package for GPU-accelerated speech-to-text transcription in the browser, leveraging WebGPU for faster Whisper model inference compared to CPU/WebAssembly-based approaches.

---

## ⚡ 功能

- WebGPU-accelerated Whisper transcription
- Faster inference compared to WASM-based alternatives
- Browser-based, no server required
