# @remotion/whisper-web

Helpers for using Whisper.cpp in browser using WASM

[![NPM Downloads](https://img.shields.io/npm/dm/@remotion/whisper-web.svg?style=flat&color=black&label=Downloads)](https://npmcharts.com/compare/@remotion/whisper-web?minimal=true)

---

## 💡 概述

A Remotion package that provides browser-based speech-to-text transcription using Whisper.cpp compiled to WebAssembly, enabling automatic caption generation within Remotion compositions.

---

## ⚡ 功能

- Browser-based Whisper.cpp transcription via WASM
- Automatic speech-to-text caption generation
- No server-side processing required
