# @remotion/web-renderer

Render videos in the browser

[![NPM Downloads](https://img.shields.io/npm/dm/@remotion/web-renderer.svg?style=flat&color=black&label=Downloads)](https://npmcharts.com/compare/@remotion/web-renderer?minimal=true)

---

## 💡 概述

A Remotion package that enables rendering videos entirely in the browser using WebCodecs and WebAssembly, eliminating the need for server-side rendering infrastructure.

---

## ⚡ 功能

- Full browser-based video rendering
- WebCodecs-based encoding
- Supports MP4 and WebM output formats

### Installation

```bash

```

When installing a Remotion package, make sure to align the version of all `remotion` and `@remotion/*` packages to the same version.
Remove the `^` character from the version number to use the exact version.
