# @remotion/webcodecs

Media conversion in the browser

[![NPM Downloads](https://img.shields.io/npm/dm/@remotion/webcodecs.svg?style=flat&color=black&label=Downloads)](https://npmcharts.com/compare/@remotion/webcodecs?minimal=true)

---

## 💡 概述

A Remotion package providing browser-based media conversion utilities built on the WebCodecs API, enabling audio and video format transcoding directly in the browser.

---

## ⚡ 功能

- Browser-based media format conversion
- WebCodecs API integration
- Audio and video transcoding support

When installing a Remotion package, make sure to align the version of all `remotion` and `@remotion/*` packages to the same version.
Remove the `^` character from the version number to use the exact version.
