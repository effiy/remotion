# @remotion/sfx

Sound effect library

[![NPM Downloads](https://img.shields.io/npm/dm/@remotion/sfx.svg?style=flat&color=black&label=Downloads)](https://npmcharts.com/compare/@remotion/sfx?minimal=true)

## 💡 概述

Sound effect library for Remotion videos. Provides a curated collection of audio effects that can be used in compositions for transitions, emphasis, and ambient sound design.

---

## ⚡ 功能

- Curated collection of sound effects
- Ready-to-use audio assets for Remotion compositions
- Covers transitions, UI sounds, and ambient effects
