# @remotion/three

Include React Three Fiber components in a Remotion video

[![NPM Downloads](https://img.shields.io/npm/dm/@remotion/three.svg?style=flat&color=black&label=Downloads)](https://npmcharts.com/compare/@remotion/three?minimal=true)

---

## 💡 概述

A Remotion integration package that enables the use of React Three Fiber 3D components within Remotion video compositions.

---

## ⚡ 功能

- Render 3D scenes in Remotion compositions
- Full React Three Fiber API compatibility
- Synchronized with Remotion's frame-based rendering

### Installation

```bash

```

When installing a Remotion package, make sure to align the version of all `remotion` and `@remotion/*` packages to the same version.
Remove the `^` character from the version number to use the exact version.
