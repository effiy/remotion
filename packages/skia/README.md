# @remotion/skia

Include React Native Skia components in a Remotion video

[![NPM Downloads](https://img.shields.io/npm/dm/@remotion/skia.svg?style=flat&color=black&label=Downloads)](https://npmcharts.com/compare/@remotion/skia?minimal=true)

---

## 💡 概述

Include React Native Skia components in a Remotion video. Enables high-performance 2D graphics rendering using the Skia graphics library within Remotion compositions.

---

## ⚡ 功能

- React Native Skia component integration in Remotion
- High-performance 2D canvas rendering
- Access to Skia's full drawing API (paths, gradients, shaders, images)
- GPU-accelerated rendering
