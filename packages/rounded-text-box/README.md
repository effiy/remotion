# @remotion/rounded-text-box

Create a TikTok-like multiline text box SVG path with rounded corners

[![NPM Downloads](https://img.shields.io/npm/dm/@remotion/rounded-text-box.svg?style=flat&color=black&label=Downloads)](https://npmcharts.com/compare/@remotion/rounded-text-box?minimal=true)

---

## 💡 概述

Create a TikTok-like multiline text box SVG path with rounded corners for use in Remotion compositions. Generates an SVG path that wraps around text content with configurable padding and corner radii.

---

## ⚡ 功能

- Generate multiline text box SVG paths
- Rounded corner support
- Configurable padding and corner radii
- TikTok-style text overlay aesthetics
