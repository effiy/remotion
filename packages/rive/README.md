# @remotion/rive

Embed Rive animations in a Remotion video

[![NPM Downloads](https://img.shields.io/npm/dm/@remotion/rive.svg?style=flat&color=black&label=Downloads)](https://npmcharts.com/compare/@remotion/rive?minimal=true)

---

## 💡 概述

Embed Rive animations in a Remotion video. Rive is a real-time interactive design and animation tool, and this package provides components to integrate Rive animations into Remotion compositions.

---

## ⚡ 功能

- Embed `.riv` files into Remotion compositions
- Control animation playback within the Remotion timeline
- Support for state machine-driven Rive animations
