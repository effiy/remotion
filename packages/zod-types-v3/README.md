# @remotion/zod-types-v3

Zod 3.22.3 types for Remotion

[![NPM Downloads](https://img.shields.io/npm/dm/@remotion/zod-types-v3.svg?style=flat&color=black&label=Downloads)](https://npmcharts.com/compare/@remotion/zod-types-v3?minimal=true)

---

## 💡 概述

Provides Zod 3.22.3 compatible type definitions for Remotion's input props schema, maintaining compatibility with projects that have not yet upgraded to Zod 3.23+.

---

## ⚡ 功能

- Zod 3.22.3-compatible schema types for Remotion
- Backward compatibility for older Zod installations
- Mirror of the zod-types package for Zod v3.22.x

## 🚀 快速开始

### Installation

```bash
npm install @remotion/zod-types-v3 --save-exact
```

When installing a Remotion package, make sure to align the version of all `remotion` and `@remotion/*` packages to the same version.
Remove the `^` character from the version number to use the exact version.
