# @remotion/transitions

Library for creating transitions in Remotion

[![NPM Downloads](https://img.shields.io/npm/dm/@remotion/transitions.svg?style=flat&color=black&label=Downloads)](https://npmcharts.com/compare/@remotion/transitions?minimal=true)

---

## 💡 概述

A Remotion library providing a declarative API for creating scene transitions between compositions, including fade, slide, and wipe effects.

---

## ⚡ 功能

- Declarative transition API
- Built-in transition effects (fade, slide, wipe)
- Composable transition sequencing

## 🚀 快速开始

### Installation

```bash
npm install @remotion/transitions --save-exact
```

When installing a Remotion package, make sure to align the version of all `remotion` and `@remotion/*` packages to the same version.
Remove the `^` character from the version number to use the exact version.
