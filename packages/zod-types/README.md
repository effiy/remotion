# @remotion/zod-types

Zod types for Remotion

[![NPM Downloads](https://img.shields.io/npm/dm/@remotion/zod-types.svg?style=flat&color=black&label=Downloads)](https://npmcharts.com/compare/@remotion/zod-types?minimal=true)

---

## 💡 概述

Provides custom Zod schema types for Remotion's composition input props, extending Zod's validation capabilities with Remotion-specific types like `z.color()` and `z.textarea()`.

---

## ⚡ 功能

- Remotion-specific Zod schema types (z.color, z.textarea, etc.)
- Type-safe input props validation for Remotion compositions
- Integration with Remotion Studio's props editor
