# @remotion/renderer

Render Remotion videos using Node.js or Bun

[![NPM Downloads](https://img.shields.io/npm/dm/@remotion/renderer.svg?style=flat&color=black&label=Downloads)](https://npmcharts.com/compare/@remotion/renderer?minimal=true)

---

## 💡 概述

Render Remotion videos programmatically using Node.js or Bun. The renderer handles frame composition, encoding, and output to video files, still images, or audio.

---

## ⚡ 功能

- Programmatic video rendering from Remotion compositions
- Support for Node.js and Bun runtimes
- Output to video, still images, and audio formats
- Integration with Remotion's rendering pipeline
