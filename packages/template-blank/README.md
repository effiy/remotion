## 💡 概述

Welcome to your Remotion project! This is the blank starter template for creating videos programmatically with React.

---

## 🚀 快速开始

**Install Dependencies**

```console
npm install
```

**Start Preview**

```console
npm run dev
```

**Render video**

```console
npx remotion render
```

**Upgrade Remotion**

```console
npx remotion upgrade
```
