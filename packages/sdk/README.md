## 💡 概述

Experimental primitives for building Remotion authoring interfaces. This SDK provides programmatic building blocks for constructing custom editing and authoring experiences on top of Remotion.

---

## ⚡ 功能

- Experimental primitives for authoring interface construction
- Building blocks for custom Remotion-based editing tools
- Programmatic composition and scene management

Remove the `^` character from the version number to use the exact version.
