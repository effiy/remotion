# @remotion/shapes

Generate SVG shapes

[![NPM Downloads](https://img.shields.io/npm/dm/@remotion/shapes.svg?style=flat&color=black&label=Downloads)](https://npmcharts.com/compare/@remotion/shapes?minimal=true)

---

## 💡 概述

Generate SVG shapes for Remotion compositions. Provides a library of geometric shapes as SVG elements that can be animated and styled within video compositions.

---

## ⚡ 功能

- SVG shape generation (circles, rectangles, triangles, stars, polygons, etc.)
- Configurable dimensions, colors, and stroke properties
- Animatable within the Remotion timeline
- Pure SVG output for crisp rendering at any resolution
